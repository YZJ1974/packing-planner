# 已知限制与复核边界

- 排箱是启发式候选搜索，不证明最少柜数或全局最优。
- 柔性袋按声明体积和重量分配；显示的袋形数量不等于实包数。不执行真实柔性形变、逐包压实或现场人工操作仿真。
- 路径、送袋距离、作业面和顶部许可依赖输入假设，现场堆放稳定性和工法仍须复核。
- 支撑和碰撞使用计算包络；圆筒曲面、局部点载、支架与木箱结构不能仅凭包络支撑通过而视为已验算。
- 未实测的设备重心按形心处理；部分审计重心仅包含已定位设备/木箱，界面会标明未含柔性袋装。袋区均匀质量估计不等于实测整柜重心。
- 吊点与吊索为假定示意，未验证吊耳、索具强度或动载，不能作为吊装施工图。
- 静态规划校核、工程输入凭证一致性和最终发运签字是不同状态，不能相互替代。
- 货车使用输入的有效尺寸、载荷和支承组模型，不自动证明道路法规、实际每轴荷载或运输许可。
- 本地 SQLite、上传文件与审批记录默认保存在 `data/`。公开测试和共享截图前应另建空目录并使用虚构样例。
- 服务器面向本机使用，不应直接以 `0.0.0.0` 暴露到互联网。
